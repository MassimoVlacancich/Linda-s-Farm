# Linda's Farm Festival

A cosy countryside festival website — bonfires between the tents, hay bales for
seating, string-lit stages, and rock, country & blues from 5pm to 1am. Runs
today through Sunday.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/` — pages: home, line-up, food, campsite, tickets
- `components/` — shared UI (nav, footer, cards, decorative bits)
- `lib/festival-data.ts` — single source of truth for dates, stages, lineup,
  food stalls, tickets, and campsite info

## Deploy

Push to a Vercel-connected repo — zero config needed.

There are a few Easter eggs scattered around the site. Have a poke around.
